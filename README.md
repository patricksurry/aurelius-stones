# Meditations

A quiet way to read Marcus Aurelius's *Meditations*, one passage at a time.

**Read it:** <https://patricksurry.github.io/aurelius-stones/>

The 488 passages are gathered on 48 *stones*: the thoughts Marcus kept returning to. The stones are grouped by Pierre Hadot's three disciplines: how to see, what to accept, and how to act. You read a passage slowly and move through its stone. When something lands, you rewrite the stone's summary in your own words, and the stone is yours. A passage counts as read only after you've spent time on it.

The study side of each card has A. S. L. Farquharson's commentary, George Long's translation, the Greek, and the historical people Marcus names. A map shows every passage and stone, and how far you've come. Progress stays in your browser; you can sign in with Google, GitHub or an emailed link to keep it across devices.

**Keys:** ↑ ↓ passages on a stone · ← → through the book · `f` study · `g` Greek · `m` map

## Repository

| Path | What |
|---|---|
| `index.html` | The whole app: plain HTML, CSS and JavaScript, with no build step |
| `sync.js` | Optional sign-in and cross-device progress (Firebase) |
| `data/meditations.js` | The dataset the app loads, generated by `build_data.py` |
| `build_data.py`, `sources.py` | Build the dataset from the archived sources |
| `raw/` | Archived copies of every source text; see [`raw/SOURCES.md`](raw/SOURCES.md) |
| `clustering/` | How passages were grouped into stones; see [`clustering/PROCESS.md`](clustering/PROCESS.md) |
| `people/` | The historical people Marcus names and their Wikipedia links; see [`people/README.md`](people/README.md) |
| `firestore.rules` | Access rules for saved progress |

Rebuild the dataset after changing any source, stone or person:

```sh
python3 build_data.py
```

Run it locally with `python3 -m http.server 8765 --bind 127.0.0.1` and open <http://localhost:8765/index.html>. Hosting and Firebase setup are in [`DEPLOYMENT.md`](DEPLOYMENT.md).

## Sources

- **English:** A. S. L. Farquharson's translation and commentary (Oxford, 1944), from Wikisource.
- **Comparison translation:** George Long's (1862), from Project Gutenberg. Both translations are public domain.
- **Greek:** J. H. Leopold's Teubner text (1908), from the Perseus Digital Library, CC BY-SA 4.0. Data derived from it stays under that licence.
- **People:** one-line descriptions and links from English Wikipedia, CC BY-SA 4.0.

Editions, revisions and retrieval dates are in [`raw/SOURCES.md`](raw/SOURCES.md).
