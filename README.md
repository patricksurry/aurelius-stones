# Meditations

A quiet way to reflect on Marcus Aurelius's *Meditations*.

Try it: https://patricksurry.github.io/aurelius-stones/

*Meditations* is more a personal journal than a book, 
and was probably not intended to be read by others, let alone read start to finish.
It was likely written more as a spiritual exercise where Marcus keeps considering and rewriting
the same set of core convictions in different words and from different perspectives.
Marcus named three key themes: how to judge, what to desire, and how to act.
This app gathers the 488 passages of *Meditations* onto 48 *touchstones* (stones, for short), themselves 
grouped by the three themes.

Rather than reading linearly, the app encourages you to reflect on one or more passages
belonging to a stone and make it your own by rewriting the summary and adding reflections.
Each stone also has study notes: A. S. L. Farquharson's commentary,
George Long's translation, and the historical figures Marcus mentions; the original Greek can sit alongside the English.
A passage counts as read only after you've spent time with it.
A progress map shows every passage and stone, and how far you've come.
Progress stays in your browser; sign in to keep it across devices.

**Keys:** ↑ ↓ passages on a stone · ← → through the book · `f` study · `g` Greek · `m` map

## Repository

| Path | What |
|---|---|
| `index.html` | The page, including the welcome text |
| `css/style.css` | All styling |
| `js/store.js` | The dataset, saved progress and shared helpers (loaded first) |
| `js/card.js` | The stone card, its study side and the related stones |
| `js/map.js` | The progress map, with clear progress at its foot |
| `js/account.js` | The sign-in line on the map and the welcome page |
| `js/app.js` | Navigation, earning reads, fading controls, theme, welcome and start-up |
| `js/sync.js` | Optional sign-in and cross-device progress (Firebase) |
| `stamp.py` | Versions the page's links to its CSS, JS and data, so browsers don't mix old and new |
| `data/meditations.js` | The dataset the app loads, generated by `build_data.py` |
| `build_data.py`, `sources.py`, `verify.py` | Build and verify the dataset from the archived sources |
| `social/` | The link-preview image and icons, and their sources; see [`DEPLOYMENT.md`](DEPLOYMENT.md#link-previews) |
| `ERRATA.md` | Transcription errors in the sources, corrected when the dataset is built |
| `raw/` | Archived copies of every source text; see [`raw/SOURCES.md`](raw/SOURCES.md) |
| `clustering/` | How passages were grouped into stones; see [`clustering/PROCESS.md`](clustering/PROCESS.md) |
| `people/` | The historical people Marcus names and their Wikipedia links; see [`people/README.md`](people/README.md) |
| `firestore.rules` | Access rules for saved progress |

Rebuild the dataset after changing any source, stone or person:

```sh
python3 build_data.py
```

Run it locally with `python3 -m http.server 8765 --bind 127.0.0.1` and open <http://localhost:8765/index.html>. Hosting and Firebase setup are in [`DEPLOYMENT.md`](DEPLOYMENT.md).

## Sources

- **English:** A. S. L. Farquharson's translation and commentary (Oxford, 1944), from Wikisource.
- **Comparison translation:** George Long's (1862), from Project Gutenberg. Both translations are public domain.
- **Greek:** J. H. Leopold's Teubner text (1908), from the Perseus Digital Library, CC BY-SA 4.0. Data derived from it stays under that licence.
- **People:** one-line descriptions and links from English Wikipedia, CC BY-SA 4.0.

Editions, revisions and retrieval dates are in [`raw/SOURCES.md`](raw/SOURCES.md).
